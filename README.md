# MicroOS

A bootc image for the AYANEO Pocket MICRO 2, built on Fedora (`quay.io/fedora/fedora-bootc:44`).

Sessions: Steam game mode, ES-DE, CASDAP and a niri desktop. Pocket MICRO 2 only.

No image is published yet.
